# Antigravity IDE Quick Reference

Graphical interface for autonomous agent execution.

## 🚀 Workflows

### 1. Goal Tab Execution
1. Open **Goal** tab.
2. Enter objective:
   * `"Read AGENTS.md and bootstrap project ('i')"`
   * `"Read AGENTS.md and generate next enhancement plan ('e')"`
   * `"Read AGENTS.md and execute next enhancement ('n' / 'n3')"`
   * `"Read AGENTS.md and execute roadmap milestone ('m')"`
3. Click **Start** to run autonomous task tree.

### 2. Model Tiering & Plan Mode
* **Deep Research (`docs/deep-research/`) & PRD (`docs/prd/`)**: Toggle to **Plan Mode** with `Pro` model.
* **Execution (`n`)**: Switch to agent execution mode.
