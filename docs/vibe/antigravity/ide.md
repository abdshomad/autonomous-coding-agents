# Vibe Coding with Antigravity IDE

The Antigravity IDE is a unified graphical development environment that integrates code editing panels, file explorers, and a built-in terminal with a powerful background AI agent orchestration engine.

## 🚀 How to Use Autonomous Workflows

### 1. Goal Tab Execution
The Goal panel allows you to track and configure autonomous runs in a graphical UI:
1. Open the **Goal** tab in the IDE.
2. In the input box, define the objective or trigger:
   * `"Read AGENTS.md and bootstrap project scaffolding ('i')"`
   * `"Read AGENTS.md and generate next enhancement plan ('e')"`
   * `"Read AGENTS.md and execute next enhancement ('n')"`
   * `"Read AGENTS.md and execute roadmap milestone ('m')"`
3. Press the **Start** button.
4. You will see a tree of sub-goals and tasks populate dynamically as the agent writes code, compiles, and verifies changes.

### 3. Model Tiering & Plan Mode
For Deep Research (`docs/deep-research/`) and PRD authoring (`docs/prd/`):
1. In the IDE model picker, select the highest-tier smart model (e.g. `Gemini 2.5/3.0 Pro` or `High Reasoning`).
2. Toggle to **Plan Mode** to perform deep discovery and architectural synthesis before switching to execution mode for `n`.
