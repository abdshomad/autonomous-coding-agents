# Caveman Skill: Token Compression Protocol

Why use many tokens when few tokens do trick. Maximize token density and cognitive efficiency.

---

## 🎚️ Intensity Modes (`/caveman [mode]`)

- `lite`: Drop filler words & pleasantries (~30% token reduction).
- `full` *(default)*: Telegraphic brevity, drop unnecessary articles/filler (~65% token reduction).
- `ultra`: Extreme micro-phrases, maximum token conservation (~75% token reduction).
- `off`: Standard prose mode.

---

## 🛡️ Verbatim Invariants

Never compress or truncate:
- Code snippets, diffs, and file paths.
- Terminal commands and execution flags.
- Exact error messages, stack traces, and test assertions.
- Root-relative path formats.
